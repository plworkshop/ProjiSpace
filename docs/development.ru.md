# Сборка и разработка

[English](development.md) · [Русский](development.ru.md) · [Обзор](../README.ru.md)

## Требования

Нужны Node.js **24.14 или новее**, npm и Git. Установите зафиксированные зависимости командой `npm ci`. Установщики собираются в соответствующей операционной системе.

| Платформа | Текущий статус |
| --- | --- |
| Windows x64 | Доступны локальная сборка и проверки в изолированном Electron. |
| macOS Intel / Apple Silicon | Ручной GitHub Actions workflow собирает обе архитектуры. Диктовка Whisper без интернета проверена на Apple Silicon. |
| Linux | Выпуск для этой платформы не предусмотрен. |

Собирайте DMG и ZIP в macOS с установленными Xcode Command Line Tools и CMake. Сборка скачивает и проверяет архив исходников заданной версии whisper.cpp, компилирует CLI для целевой архитектуры и подписывает приложение ad hoc. Для подписи Developer ID и нотарификации нужны отдельные данные разработчика.

## Команды

```sh
npm ci
npm run desktop
npm test
npm run build
npm run desktop:test
```

| Команда | Назначение |
| --- | --- |
| `npm run dev` | Локальная веб-разработка: `http://127.0.0.1:5173`. |
| `npm run build` | Проверка уведомлений и TypeScript, сборка интерфейса. |
| `npm start` | Запуск собранной веб-версии: `http://127.0.0.1:4317`. |
| `npm run desktop` | Сборка и запуск Electron из исходников. |
| `npm run desktop:build:win` | Установщик Windows x64 в Windows. |
| `npm run desktop:build:mac` | Варианты сборки macOS в macOS. |
| `npm run desktop:test` | Проверка в изолированном временном профиле Electron. |
| `npm run notices` | Обновление уведомлений о сторонних зависимостях. |

Не запускайте сервер разработки и собранную веб-версию одновременно: им нужен один API-порт. Веб-режим рассчитан на локальную работу одного пользователя. Не публикуйте его как сетевой сервис. В новом веб-хранилище один раз создаются демонстрационные проекты; настольное хранилище изначально пустое.

## Функции по платформам

Проекты, изображения, планы и локальное хранение используют общие исходники. Необязательный ИИ-помощник обращается к локальной Ollama. Установка и запуск среды реализованы для Windows; в macOS нужна уже запущенная Ollama. Диктовка использует одну и ту же модель Whisper в Windows x64 и в собранном приложении macOS.

## Данные и совместимость

Веб-режим из исходников использует папку `data/` в репозитории. Electron использует системную папку данных приложений и профиль `Projector`, если пользователь не выбрал другое место хранения. Идентификаторы `sidequest.sqlite` и `app.sidequest.desktop` сохранены для совместимости; их переименование может нарушить доступ к прежним данным и обновлениям.

Автоматические тесты создают временные хранилища. Никогда не направляйте их на личную базу. Папки `qa/`, `data/`, `release/` и зависимости исключены из Git.

## Проверки перед выпуском

Выполните тесты, сборку интерфейса и проверку настольной программы на каждой целевой платформе. Проверьте содержимое сборки и подготовьте контрольные суммы распространяемых файлов. Установщики размещаются в GitHub Releases, а не среди исходников. Подготовка workflow сама по себе не публикует выпуск.

При изменении зависимостей выполните `npm run notices` и включите обновлённый `public/THIRD_PARTY_NOTICES.txt`. Сохраняйте уведомления [шрифта](../public/fonts/OFL.txt), [распознавания речи](../desktop/voice/NOTICE.txt) и Electron вместе с соответствующими файлами.

## Неполадки

- **Диск с хранилищем недоступен:** подключите его и перезапустите программу. Новое пустое хранилище вместо прежнего не создаётся.
- **Помощник недоступен:** запустите локальную Ollama, откройте настройки и выберите установленную поддерживаемую модель.
- **Диктовка недоступна в macOS:** используйте собранное приложение и проверьте доступ к микрофону в разделе «Конфиденциальность и безопасность» системных настроек.
- **Неподписанная локальная сборка не создаётся:** проверьте настройки подписи и используйте workflow в целевой ОС. Не отключайте защиту ОС ради запуска непроверенной загрузки.

## Ресурсы бренда

Исходные SVG интерфейса находятся в `public/brand/icon.svg` и `public/brand/wordmark.svg`. Иконка приложения использует `public/brand/app-icon.png`. После замены PNG выполните `npm run brand:build`, чтобы обновить PNG для приложения и Windows ICO с несколькими размерами. Преобразование сохраняет пропорции и прозрачность рисунка.
