# Участие в разработке

[English](CONTRIBUTING.md) · [Русский](CONTRIBUTING.ru.md)

Можно сообщать об ошибках и предлагать конкретные улучшения. Сначала проверьте существующие обращения и опишите решаемую проблему. Проект имеет доступные исходники на условиях [лицензии ProjiSpace](LICENSE.ru.md); в будущем возможны закрытые функции. До отправки кода обсудите изменение, чтобы согласовать его объём и условия использования. Дополнительное соглашение с участником здесь не вводится.

## Сообщить об ошибке

Укажите версию приложения, операционную систему, шаги воспроизведения, ожидаемое и фактическое поведение. Используйте вымышленные проекты на снимках экрана. Не прикладывайте базу проектов, записи голоса, ключи доступа или личные пути к файлам. Для уязвимостей действует [SECURITY.ru.md](SECURITY.ru.md).

## Подготовить изменение

1. Используйте Node.js 24.14 или новее и установите зависимости: `npm ci`.
2. Решайте одну задачу за раз, сохраняя совместимость существующих данных.
3. Для изменения поведения добавьте содержательную проверку. Используйте временное хранилище вместо личных проектов.
4. Выполните `npm test` и `npm run build`. Для настольного приложения также запустите `npm run desktop:test` в поддерживаемой среде.
5. При изменении зависимостей выполните `npm run notices` и включите обновлённые уведомления о лицензиях.

См. [инструкцию по разработке](docs/development.ru.md). Обновляйте документацию на обоих языках. Не включайте в коммиты `node_modules`, данные проектов, модели, журналы, ключи подписи и результаты сборки.
