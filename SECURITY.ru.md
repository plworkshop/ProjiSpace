# Безопасность и конфиденциальность

[English](SECURITY.md) · [Русский](SECURITY.ru.md)

ProjiSpace — локальное приложение для одного пользователя. Используйте последний выпуск. Фиксированный срок ответа на уязвимости, автоматическое обновление и выпуск с цифровой подписью не гарантируются.

## Границы защиты

- Окно настольного приложения работает в песочнице без интеграции Node.js. Локальный API использует сессию, создаваемую при каждом запуске.
- Веб-сервер и сервер разработки предназначены для локальной работы. Не открывайте их через публичный интерфейс, туннель или обратный прокси.
- Описания очищаются перед отображением. Для изображений ограничены тип и размер, имена файлов генерируются приложением.
- Необязательные запросы помощнику направляются в локальную Ollama. Изменения применяются только после просмотра и подтверждения. Помощник не может запускать команды, обращаться к произвольным файлам или удалять проекты.
- В Windows и macOS диктовка Whisper работает локально после загрузки модели. Временное аудио удаляется после завершения или отмены распознавания. При аварии временный файл может остаться на диске.

ProjiSpace не шифрует хранилище. Другое ПО с правами того же пользователя ОС может получить к нему доступ. Для чувствительных данных используйте защиту учётной записи и диска средствами ОС. Отдельно установленная Ollama относится к доверенной локальной среде.

## Сообщить об уязвимости

Используйте **Security → Report a vulnerability** в этом репозитории, если включены приватные сообщения об уязвимостях GitHub. Если формы нет, запросите закрытый канал связи, не публикуя технические подробности. Публичный адрес для связи не указан.

Укажите версию, платформу, режим запуска, шаги воспроизведения, ожидаемую границу защиты и возможные последствия. Уберите из примеров личные проекты, записи голоса, ключи и личные пути. Не публикуйте детали эксплуатации или конфиденциальные данные в открытом обращении.

## Что подтверждают проверки

Автоматические тесты и проверка зависимостей снижают риск, но не гарантируют отсутствие уязвимостей. Сборка и проверка запуска выполняются отдельно для каждой платформы. Текущий статус указан в [инструкции для разработки](docs/development.ru.md).
