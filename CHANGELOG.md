# Changelog

[English](CHANGELOG.md) · [Русский](CHANGELOG.ru.md)

## 1.0.0

Initial public-source revision.

- Project card picker, random selection, search, pinning and subprojects.
- Rich descriptions, four project statuses, images, links and image markup.
- Milestones, deadlines, date notes and resizable workspace panels.
- Local storage with folder selection and restart-based transfer.
- Optional local AI proposals and voice dictation.
- English/Russian interface and light/dark themes.
- Bilingual documentation and platform build configuration.

The browser extension is not part of this revision. Platform-specific availability is recorded in [Build and development](docs/development.md).
